# constraints.txt — versions testées des dépendances de moisson-shs.
#
# Rôle : figer l'environnement dans lequel la suite de tests est verte, pour
# que l'image Docker, la CI et tout venv neuf reproduisent le même jeu de
# paquets. Ce fichier CONTRAINT sans rien installer par lui-même : seules les
# dépendances réellement demandées (projet + extras choisis) sont installées,
# aux versions ci-dessous quand elles y figurent.
#
# Usage :
#   pip install -e ".[dev,mcp]" -c constraints.txt       (développement, CI)
#   pip wheel --wheel-dir /wheels ".[mcp]" -c constraints.txt   (Dockerfile)
#
# Les bornes larges de pyproject.toml (dont `mcp>=1.27,<2`) disent ce qui est
# SUPPORTÉ ; ce fichier dit ce qui est TESTÉ. Pour monter une version : la
# modifier ici, relancer la suite complète (y compris les tests `sockets`), puis
# reconstruire l'image. Ne jamais franchir mcp 2.x ici : la série 2 retire les
# décorateurs `Server.list_tools` / `call_tool` / `list_resources` sur lesquels
# repose mcp_server.py (migration = chantier distinct, cf. DEPLOY.md).
#
# Relevé initial : `pip freeze` du venv de développement (Python 3.14) où la
# suite passe, vérifié installable sous Python 3.10, 3.11 et 3.12 (Linux
# x86_64 et aarch64, macOS arm64). Les deux dernières lignes ne s'appliquent
# qu'à Python 3.10 (rétroportages absents d'un venv 3.14).
